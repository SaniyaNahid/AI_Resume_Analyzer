# AI Resume Analyzer

An AI-powered web application that analyzes resumes using Gemini AI.

## Features

- Resume upload
- AI analysis
- ATS score
- Skill extraction
- Improvement suggestions

## Tech Stack

### Frontend
- React
- Vite

### Backend
- FastAPI

### AI
- Gemini API

## Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
